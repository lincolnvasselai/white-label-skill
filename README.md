# White label skill

Setup wizard for the [White Label Design System](https://www.figma.com/design/tAVy1duQqnqRCYEhc1SA1l/White-Label-%7C-Design-System) variable structure.

The skill lives in `.cursor/skills/white-label-setup`. Open this repo in Cursor and ask to set up a new brand. The agent asks how many brand colors and fonts you have, which ones are primary, secondary, and tertiary, then writes those answers into the existing tokens.

One Figma file per brand. Collection names, modes, and semantic token names stay as they are in the source file.

## Share with the team

Clone this repo and open it in Cursor. The skill is available in this project.
