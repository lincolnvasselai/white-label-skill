# White label skill

Setup wizard for the [White Label Design System](https://www.figma.com/design/tAVy1duQqnqRCYEhc1SA1l/White-Label-%7C-Design-System) variable structure.

The skill lives in `.cursor/skills/white-label-setup`. Open this repo in Cursor and ask to set up a new brand. The agent asks for the brand name, then how many brand colors and fonts the brand has, which ones are primary, secondary, and tertiary. Answers replace the source defaults for those slots.

The source file is the White Label Design System. One Figma file per brand. The source default primary color in Core is `color/blue/500` `#0092d8`, with shades built from that hex. A new brand replaces that ramp. Collection names, modes, and semantic token names stay as they are in the source file. Unchanged tokens keep the source defaults.
